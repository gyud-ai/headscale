iOS configuration

GUI

  1. Install the official Tailscale iOS client from the App Store
  2. Open the Tailscale app
  3. Click the account icon in the top-right corner and select Log in…
  4. Tap the top-right options menu button and select Use custom coordination server
  5. Enter your instance URL: {{.Site.ServerURL}}
  6. Enter your credentials and log in. {{.Site.Name}} should now be working on your iOS device

macOS configuration

Command line

Use Tailscale's login command to add your profile:

tailscale login --login-server {{.Site.ServerURL}}

GUI

  1. Option + Click the Tailscale icon in the menu and hover over the Debug menu
  2. Under Custom Login Server, select Add Account...
  3. Enter {{.Site.ServerURL}} of the {{.Site.Name}} instance and press Add Account
  4. Follow the login procedure in the browser

Profiles

{{.Site.Name}} can be set to the default server by installing a configuration profile:

macOS AppStore profile macOS Standalone profile
  1. Download the profile, then open it. When it has been opened, there should be a notification that a profile can be installed
  2. Open System Preferences and go to Profiles
  3. Find and install the {{.Site.Name}} profile
  4. Restart Tailscale.app and log in
or

Use your terminal to configure the default setting for Tailscale by issuing one of the following commands:

For app store client:

defaults write io.tailscale.ipn.macos ControlURL {{.Site.ServerURL}}

For standalone client:

defaults write io.tailscale.ipn.macsys ControlURL {{.Site.ServerURL}}

Restart Tailscale.app and log in.

tvOS configuration

GUI

  1. Install the official Tailscale tvOS client from the App Store
  2. Open Tailscale
  3. Select Install VPN configuration
  4. Select Allow, but don't sign in yet
  5. Open Settings (the Apple tvOS settings) > Apps > Tailscale
  6. Enter {{.Site.ServerURL}} under ALTERNATE COORDINATION SERVER URL
  7. Return to the tvOS Home screen and open Tailscale
  8. Scan the QR code and follow the login procedure
  9. {{.Site.Name}} should now be working on your tvOS device
